# Resume

LaTeX source for my current resume. Principal engineer, Java and Scala, applied AI in fintech.

Compile with MiKTeX or TeX Live:

```bat
pdflatex waqar_shaikh_resume.tex
```

The PDF is not committed. Generate it locally. Phone and email are in the source because this file is the resume.

## Resume editor (index.html)

Open `index.html` in a browser. Edit the fields on the left and the A4 preview on the right updates live. Your edits are saved in the browser's localStorage, and **Reset** puts the defaults back.

- **Render PDF** opens the print dialog. Choose *Save as PDF*, A4, no margins/headers. The result is a single column with real bullets, so ATS parsers can read it.
- **Download LaTeX** saves a complete `waqar_shaikh_resume.tex` built from the form, in the same layout as the file in this repo. Compile it with `pdflatex`.
